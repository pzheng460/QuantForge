# 近3年暴涨股共性研究：2023–2025 复盘（以 Palantir 为锚）

> 研究方法：按年收集标普500/纳斯达克领涨股 + 中小盘暴涨股（>300%年涨幅或单日爆发），
> 逐一比对驱动事件、基本面拐点、仓位与流动性结构，归纳共性。
> 数据来自公开新闻与行情综述（文末列出来源）。本报告为研究笔记，不构成投资建议。

## 二、共性提炼（按重要性排序）

### 1. 万变不离其宗：都是"AI 资本开支"的下游/上游
最硬的共性不是"科技"，而是**踩中 AI 算力投资这条资金主线的某个环节**：

- **算力芯片**：NVDA、AMD、AVGO、MU、WDC、STX、LRCX、AAOI
- **电力/能源（AI 的"铁锹"）**：VST、GEV、TPL、TRGP、IREN（矿场转算力）
- **AI 软件/平台**：PLTR、PANW、META、AXON
- **数据中心基建**：FIX（暖通机电）
- **算力租售**：HOOD 是"AI 交易/散户基建"+ 加密

纯靠传统基本面（疫后旅游 RCL/CCL、金价 NEM、地产 BLDR/PHM）翻倍的也有，但**年涨 200% 以上且能持续**的，
基本都落在 AI 主线或"AI 化"公司上。2025 年连存储器这种周期股都被 AI 重新定价。

### 2. 真正持续的暴涨股都把"AI 叙事"变成了"财报里的钱"
2025 年被称作"Great Divergence"（大分化）：Alphabet +66%、Nvidia 与 Tesla 机器人出租车跑赢，
而 Amazon 仅 +5.5%——**市场开始惩罚"巨额资本开支但没有兑现到收入"的公司，奖励"可验证的变现"**。
Palantir 是最典型：美国商业收入 +121%，连续 12 个季度 GAAP 盈利，Rule of 40 达 114%，
管理层一次次上调全年指引。**重复暴涨（PLTR、NVDA、HOOD、FIX 连续两年上榜）的，全是收入与 EPS 加速的**，
不是纯概念。

### 3. 起点总是一个"超预期触发器"（catalyst），且大多与财报指引有关
暴涨很少是慢慢涨出来的，几乎都从某个**预期差事件**开始：

| 触发器类型 | 案例 |
|---|---|
| 财报指引大超预期 | AAOI(+67%单日)、MU/WDC(HBM)、NVDA |
| 巨型合同/政策 | PLTR 陆军百亿美元单 + NATO、LRCX 存储设备 |
| 债务/资本结构拐点 | CVNA 债务重组 |
| 临床/监管数据 | SLNO 三期数据(+505%单日) |
| 指数纳入 | PLTR 2024-09 进标普500（"分水岭"）、HOOD |

其中**"盈利指引超预期"（guidance shock）最可复制、可跟踪**——这是财报季前无法完全定价、财报后马上被重新定价的变量。

### 4. 低位 + 高空头 = 杠杆放大器（并非全部，但解释极端涨幅）
统计上，**年涨幅最大的个股往往 12 个月前被打得很惨**：
- CVNA：2022 年底 3.55 美元（破产恐慌），2023 年 +1079%，空头借券率一度 47~65%
- MU/WDC：2025 年前被长期做空的周期股，AI 反转后暴力回补
- META：2022 年跌 64% 后 2023 年翻两倍
- TSLA：2022 年 -65% 后 +102%

**同样的基本面改善，起点越低、空头越拥挤，名义涨幅越夸张。** 这也是为什么 PLTR 这类
"从高位一直涨"的反而显得"慢"——它的 +340% 是基本面驱动的真实重估，而 CVNA 的 +1000% 里
有大量逼空成分。

### 5. 结构性的买方力量：指数纳入 + 散户/零售资金
- **指数纳入带来被动资金买入**：PLTR 进标普500、HOOD 进标普/纳指，形成"越涨越买"的顺风。
- **零售资金是放大器**：PLTR 2025 年被散户净买入近 80 亿美金（全市场第5），FOX 刻意经营散户关系；
  HOOD 本身就是散户交易平台，是"交易量牛市"的直接受益者。
- 高波动 + 高叙事强度 = 自动吸引期权投机与 FOMO，进一步放大波动。

### 6. 政策与宏观"顺风期"
- 2023：加息见顶，成长股估值修复；
- 2024-2025：AI 军备竞赛 + 电力短缺 + "国防超级周期"（Golden Dome 千亿美元防御计划、NATO Maven、军费扩张）；
- 特朗普减税法案(2025)：研发费用化、100% 资本开支加速折旧，直接利好半导体/数据中心。
暴涨股往往出现在**某个产业周期 + 政策周期共振**的年份。

### 7. 赢家通吃：涨幅极度集中
Bessembinder 研究：1926 年以来不到 4% 的股票贡献绝大多数财富增长，且集中度在上升——
Mag7 约占标普500市值的 34%、涨幅的 ~54%。2025 年纳斯达克 top10 平均 +784%、中位数仅 +354%，
**最锋利的上涨由极少数"超级明星"贡献**。这意味着"抓共性能不能出票"，本质是你能不能提前识别
少数几个进入收入加速期的公司。

## 三、反例与边界（哪些"共性"是幸存者偏差）

1. **不是所有暴涨股都盈利**：WBD、CVNA 暴涨起点是亏损/微利——它们靠的是"利空出尽 + 逼空"，不可持续；
   但**第二年还能继续暴涨的全是转盈利或持续盈利的**（PLTR、NVDA、HOOD、FIX）。
2. **不是只有 AI**：金价(NEM)、旅游(RCL/CCL)、地产(BLDR/PHM)也上榜——这些是周期/均值回归型，暴涨后回撤大。
3. **暴涨≠可买入**：多数暴涨股在事后估值极高（PLTR 峰值 P/E 450-850x，华尔街平均评级"持有"），
   且历史显示（对比 2000 年互联网泡沫）**领涨股的平均涨幅甚至高于 2000 年泡沫顶点**，追高风险极大。
4. **每轮牛市都有自己的"AI"**：2000 年是互联网，这次是 AI。**判断共性要抓"当期资本开支主线"，而不是机械套用上轮名单。**

## 四、可量化的"前置信号清单"（供策略筛选参考）

如果要把上述共性转成可回测的筛选条件（QuantForge 可用财报/行情数据回测），按出现时间排序：

1. **EPS/收入加速**：连续 2-3 个季度收入同比增速上行（second derivative > 0）
2. **指引上修**：财报后分析师一致预期被显著上修（guidance shock，财报次日跳空 >5% 是强信号）
3. **估值起点低/空头拥挤**：短期缺口、空头借券率高（>20% float）、股价处于多年低位
4. **主题归属**：处于当期资本开支主线（当前是 AI 上游算力/电力/存储/软件平台）
5. **盈利拐点**：从亏损转盈亏平衡/首次大幅转正的季度
6. **流动性事件**：指数纳入公告、大额回购/增持、结算(settlement)缩短带来的成本下降
7. **行为信号**：期权成交量激增、call 持仓集中、散户资金流排名前列（这些是放大器，不是因）

> 注意：以上大多是**事后才能确认**的（指引上修、散户流、指数纳入都发生在暴涨之后）。
> 真正可前置的是 **①主题归属 + ②收入加速 + ③低估值起点/空头拥挤**——这三者可以提前筛选。
> 有效策略的难点是"在暴涨前买入、在估值脱离基本面前卖出"，报表数据（收入/指引）天然滞后。

---

## 五、结论（一句话版）

> **近3年暴涨股的共性 = 踩中当期最大产业资本开支主线（AI）+ 财报出现可验证的收入/EPS 加速
> （而非纯概念）+ 一个"超预期"触发器（通常是指引上修）+ 低起点/高空头或高关注度的结构性放大 +
> 主题与政策周期共振 + 赢家通吃下的高集中度。** 其中最可复制、最可跟踪的是"收入加速 + 指引上修"，
> 最危险的是把"爆发力"当成"可预测性"——多数暴涨无法事前捕捉，回测时务必警惕幸存者偏差与滞后信息。

## 六、第二层数据可得性实测（在本机环境逐项验证）

针对"收入/EPS 加速、盈利超预期、空头拥挤"三类信号，数据源在本机逐项实测验证
（实测记录见数据工程流水线 `apps/research/` 与 `data/README.md` 的迁移说明）。

### ✅ 免注册、当场可用的（已验证）

| 信号 | 数据源 | 实测结果 |
|---|---|---|
| **历史盈利超预期序列**（第二层最核心） | yfinance `Ticker.earnings_dates` | 25 个季度（≈6 年），含 `EPS Estimate / Reported EPS / Surprise(%)`，索引进=财报公告日 → **天然 point-in-time，无前视偏差**。PLTR/MU/CVNA 全部取到 |
| 年度收入/EPS 5 年历史 | yfinance `income_stmt`（年度） | 5 年 x 45 行科目，免费，但粒度粗 |
| 分析师当前一致预期 | yfinance `earnings_estimate` / `revenue_estimate` | 0q/+1q/0y/+1y 四个期的 avg/low/high/分析师数/增速 |
| 分析师短期修正计数（当前快照） | yfinance `eps_revisions` | 近 7/30 天上调/下调家数（仅当前，无历史） |
| 当前空头快照 | yfinance `Ticker.info` | shortPercentOfFloat / sharesShort / 上月值 |
| 财报日历 | `earnings_dates` 索引 | 历史每次财报公告日 |

### 🔶 需要免费注册 API key（约 5 分钟，免费额度够回测）

| 信号 | 数据源 | 说明 |
|---|---|---|
| **季度收入/净利 5 年历史** | Alpha Vantage `INCOME_STATEMENT`（免费 25 次/天）或 FMP 免费档（约 250 次/天） | 补齐"季度收入加速"信号。⚠️ Yahoo 官方 fundamentals-timeseries 接口实测**时好时坏（间歇性返回空）**，不可依赖 |
| **历史空头序列（全市场，每两周）** | FINRA `api.finra.org` `equity/equityShortInterest` | 无 key 返回 401，注册免费 key 后可拉（OTC-only 数据集不用注册但含金量低） |

### ❌ 免费拿不到的（真实缺口，需用代理）

| 信号 | 缺口 | 免费替代方案 |
|---|---|---|
| **分析师"指引上修"历史时间序列** | 只有当前快照，无历史修订曲线；真数据在 IBES/Zacks/Capital IQ（付费，数千$/年） | ① `earnings_dates` 超预期序列（近似"盈利上修"）② 财报后价格反应/跳空（earnings gap，用现有价格数据即可）③ `eps_revisions` 当前计数做截面排名 |
| **公司经营管理层收入指引（guidance）历史** | 散落在财报电话会/新闻稿，无结构化免费源 | 以"财报后跳空 + 超预期"作为行为代理 |

### 结论：第二层 ~80% 可落地
- **最重要、最可复制的信号（盈利超预期 + 盈利拐点）已经免费拿到**，且天然对齐公告日；
- 季度收入历史 + 历史空头需要各注册一个免费 key，半天内可以打通；
- 真正缺的是"分析师预期修订历史曲线"，用 `earnings_dates` 超预期序列 + 财报跳空做代理，信息损失可控。
